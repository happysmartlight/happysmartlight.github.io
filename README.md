# Happy Smart Light

Official landing page and interactive showcase for **Happy Smart Light (HSL)** - Specializing in ARGB HSL smart LED control ecosystems.

## Core Technologies
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 (with custom `@plugin`, `@theme` layer inside `src/index.css`)
- **Animation:** `motion/react` (Framer Motion API)
- **Icons:** `lucide-react`
- **Routing:** Handled via component state rendering in `App.tsx` (Single Page Application without external React Router for simplicity).

## Quick Start
1. **Install Dependencies:**
   ```bash
   npm install
   ```
2. **Run Development Server:**
   ```bash
   npm run dev
   ```
3. **Build for Production:**
   ```bash
   npm run build
   ```

## Key Features
- **Hero Interactive Showcase:** Simulates controller protocols and FPS capabilities in real time.
- **Interactive App Showcase:** Features a dynamic environment simulator with SVG/CSS-based physics (Stage Lighting, Car Underglow, Game Sync, Matrix, POI).
- **Product Ecosystem Graph:** Shows how different hardware nodes communicate via WiFi/Art-Net.
